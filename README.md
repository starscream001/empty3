# Сайты на заказ — демо-шаблоны

Репозиторий для быстрых конфигурируемых демо-сайтов. Каждый тип бизнеса лежит в отдельной папке внутри `templates/` и может настраиваться без правки структуры страницы.

## Доступные шаблоны

- `templates/auto-service/` — четыре дизайна сайта автосервиса с общим конфигом, услугами, акциями, отзывами, мессенджерами и картами.

## Корневая витрина

Корневой `index.html` — это будущая витрина направлений. Она показывает активные демо и очередь шаблонов, которые можно добавить следующими. Данные карточек сейчас находятся в `script.js`, а рабочие шаблоны лежат отдельными папками в `templates/`.

## Принцип настройки

1. Выберите нужную папку в `templates/`.
2. Откройте локальный `config.js`.
3. Замените данные клиента, услуги, цены, CTA и изображения.
4. Откройте `index.html` или запустите локальный сервер.

## Локальный сервер

```bash
python3 -m http.server 8000
```

После запуска витрина будет доступна по адресу `http://localhost:8000`, а выбор дизайна автосервиса — по адресу `http://localhost:8000/templates/auto-service/showcase.html`.

## Важно про контакты

В конфиге хранятся только публичные ссылки на телефон и страницы мессенджеров. Токены ботов и другие секреты в клиентский JavaScript добавлять нельзя.
