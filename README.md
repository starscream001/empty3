# Сайты на заказ — демо-шаблоны

Репозиторий для быстрых конфигурируемых демо-сайтов. Каждый тип бизнеса лежит в отдельной папке внутри `templates/` и может настраиваться без правки структуры страницы.

## Доступные шаблоны

- `templates/auto-service/` — четыре дизайна сайта автосервиса с отдельными конфигами клиентов, услугами, акциями, отзывами, мессенджерами и картами.

## Корневая витрина

Корневой `index.html` — это будущая витрина направлений. Она показывает активные демо и очередь шаблонов, которые можно добавить следующими. Данные карточек сейчас находятся в `script.js`, а рабочие шаблоны лежат отдельными папками в `templates/`.

## Принцип настройки

1. Выберите нужную папку в `templates/`.
2. Скопируйте пример клиентского конфига и заполните данные бизнеса.
3. Добавьте клиента в локальный `manifest.json`.
4. Откройте клиентскую витрину или запустите локальный сервер.

## Локальный сервер

```bash
python3 -m http.server 8000
```

После запуска общая витрина будет доступна по адресу `http://localhost:8000`, а выбор дизайна автосервиса — по адресу `http://localhost:8000/templates/auto-service/showcase.html?client=prime-service`.

## Важно про контакты

В конфиге хранятся только публичные ссылки на телефон и страницы мессенджеров. Токены ботов и другие секреты в клиентский JavaScript добавлять нельзя.
