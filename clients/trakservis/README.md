# ТракСервис — персональные грузовые демо

Витрина: https://qasite.ru/clients/trakservis/

Четыре дизайна доступны через `site.html?design=industrial`, `nordic`, `graphite`, `technical`.
Тексты и варианты находятся в `app.js`, оформление — в `style.css`. Сайт статический; кнопки связи открывают телефон, почту и ВКонтакте. Формы с фиктивной отправкой нет. Демо закрыты от индексации.

Контакты, перечень работ и график перенесены из предоставленных пользователем скриншотов группы https://vk.ru/truck60: работа с 2008 года, Пн–Пт 09:00–18:00, +7 (931) 901-74-77, trakservis-psk@mail.ru, Псков, Леона Поземского, 121к1. Скриншоты не включены в публичный репозиторий.
